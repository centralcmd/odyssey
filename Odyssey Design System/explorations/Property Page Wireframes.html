?Inventory & open questions

Basic fields (draft)

  • Name / nickname
  • Type: house, apartment, cabin, plot, garage, commercial
  • Address + coordinates
  • Property / cadastral ID
  • Ownership: owned / rented / share %
  • Owners (contacts)
  • Year built, living area, plot size, rooms
  • Purchase date & price
  • Current estimate (reuse Account estimates?)
  • Notes

Event categories

  • Purchase / sale
  • Valuation
  • Maintenance / renovation
  • Inspection
  • Tax & fees
  • Insurance / claim
  • Tenancy (move in / out)
  • Other

Open questions

  • Is a property its own entity, or an Account (asset) with extra fields? Contracts already link account 7 as the Property party.
  • Should events be manual only, or also auto-generated (contract signed, transaction tagged, valuation added)?
  • Documents & photos: new storage, or the existing Files / Photos modules with a property link?
  • Rented homes and rented-out properties too, or owned only?
  • Is a map tile provider OK (privacy / self-hosting), or a static map / "open in maps" link?

?Shapes, doors, windows

Data shape (rough)

  • Room → polygon: list of (x, y) in cm
  • Wall → segment between two points, thickness, exterior?
  • Door → wall, offset, width, height, swing, type
  • Window → wall, offset, width, height, sill, glazing, year
  • Stairs → links two floors

What it unlocks

  • Area calculated from shape
  • Window list for replacement / quotes
  • Door & window events (replaced, sealed)
  • Room adjacency (which rooms connect)

Open questions

  • Full editor (K), trace over image (L), or both — trace first, edit later?
  • Curved walls, or straight segments only?
  • Are doors and windows records with their own log and documents, or just drawing marks?
  • Measurements entered as numbers, or only drawn?
