Contact types

The two members of the ContactType enum (v5 — collapsed from six) — the kind of entity money moves to or from, either a Person or an Organization (ordinals Person=1, Organization=2). The enum itself carries only a name; the icon and color are a design-system decision, defined once in the contactTypes registry so the table avatar, the type chip, the detail tile, and the picker all render a type identically. Hues share the categorical chroma/lightness band with the account-type registry, so the two read as one visual family. The former Merchant / Company / Institution / Other values all fold into Organization.
