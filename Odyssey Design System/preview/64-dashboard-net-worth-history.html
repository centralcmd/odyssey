Dashboard · Net worth

Every series point is reconstructed from stored data as of that point's instant. There is no fallback series: when the data is not there, the chart is not there, and the copy names which cause applies rather than saying "no data". Property value is its own asset line; every property term below applies only when that response's PropertiesIncluded is true (see 64b).
