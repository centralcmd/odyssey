File type pickers

Six typed, domain pickers — one pair per file-type enum. AccountFileTypeSelect / …MultiSelect are pre-wired to ACCOUNT_FILE_TYPES (files on an account); TransactionFileTypeSelect / …MultiSelect to TRANSACTION_FILE_TYPES (files on a transaction); TaxStatementFileTypeSelect / …MultiSelect to TAX_STATEMENT_FILE_TYPES (files on a tax statement). The single-selects delegate to the shared TypeSelect; the multis wrap MultiSelect. Every option shows its Material icon in its category color, with no per-call option wiring. Value is the enum key; everything the control accepts (label, help, error, disabled…) passes straight through. Pass types to subset.
