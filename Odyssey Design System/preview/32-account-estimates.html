Account value estimates · accounts/{id} → Estimates

A time-versioned history of an account's estimated value — a single money amount in the account's own currency, effective from a date — living as a new section inside the expanded account record, positioned above Terms. It's the sibling of the Terms feature for assets the transaction ledger can't represent (a house, a car). The latest entry on or before a date is the value in force (implicit supersession — no EffectiveTo). It leads with the current value, a value chart over time, then the full editable history. The current estimate replaces the transaction balance in net worth — shown here as the headline, with the transaction balance kept as a quiet secondary.

DTO NewAccountEstimate · ExistingAccountEstimate · CurrentAccountEstimate Entity AccountEstimate API AccountController /estimates Claims accounts.estimates.{read,write}
  • show_chartDiscrete appraisals, held flat. An estimate holds until the next one supersedes it, so the chart steps — but it can also read as a smooth value trend (tweak below); both extend the current value to a dashed Today marker.
  • account_balanceEstimate replaces balance in net worth. When an estimate exists it is the account's contributed value; the transaction balance stays visible but quiet. A Property with no transactions still contributes its estimated worth.
  • tuneTweak the surface. Toggle the value chart (step / smooth), the history view (table / timeline) and the empty-state treatment (standard / guided) in the bar below.
  • recommendEvery account type is eligible. A recommended subset (Property · Vehicle · Other asset · Investment · Pension) is highlighted in the dialog, but estimates are never blocked on any type.
