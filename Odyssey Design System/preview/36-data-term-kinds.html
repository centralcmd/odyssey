Term kinds

The TermKind enum classifies each entry in an account's rate & fee history (the AccountTerm feature). Two rates — InterestRate and the optional ExpectedReturn — lead; four fees follow. Like every Odyssey registry, the enum carries only a name; the group, icon, color and default unit are a design-system decision, defined once in OdysseyData.termKinds so a kind reads identically in the step chart, the current-terms summary, the history, the picker and the row subtitle. Hues sit in the shared categorical band (L ~0.74–0.80, C ~0.13–0.16) — brand tide stays out of it, and the kinds never encode income / expense / status. Each kind is gated to the account types it can apply to.

  • ruleEligibility is a matrix, in code. InterestRate only on interest-bearing accounts; ExpectedReturn only on Investment / Pension; the four fees on every account type. It lives in termKindEligibility (not the DB) so it can change without a migration; the New term dialog hides ineligible kinds.
