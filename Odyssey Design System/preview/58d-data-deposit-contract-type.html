Deposit — the contract under which the household places money

Odyssey could file a Loan, where the household borrows, but not the reverse: a fixed-term bank deposit, a notice account, a rental deposit held by a landlord. Those were filed as Other, or as a Loan with Lender and Borrower read backwards. This adds one contract type and two roles. There is no new screen, dialog or component — only three registry rows and one matrix column, which every existing surface already reads.

Notes for the implementer

  • lock_clockDeposit uses lock_clock at hue 258. The glyph reads as money set aside for a term. The hue sits in the widest remaining gap on the type wheel, between Employment (225) and Insurance (290); Other at 250 is near-achromatic and does not compete.
  • account_balanceCustodian reuses account_balance, the bank glyph the Institution contact type already uses, the same way Insurer shares shield with Insurance. It never sits beside the Loan type chip, because Custodian is rejected on Loan. Depositor takes account_balance_wallet.
  • link_offThe Custodian role and an account's custodian stay independent. The seeded deposit names Ally Bank as Custodian, which is also Ally Savings' account custodian. Nothing links, syncs or cross-checks the two.
  • delete_outlineCustodian does not block contact deletion. Only Beneficiary refuses with a 409; deleting a Custodian contact cascades its party row away and the contract survives.
  • lockCollateral is allowed on Deposit, suggested on Loan. Its description now covers both: security on a loan, or a deposit blocked to secure a lease.
  • historyVersion skew needs nothing new. An older client shows 9 as Other (the trailing fallback) and 20/21 as Unrecognised role with Edit party withheld.
