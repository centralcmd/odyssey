Property events · properties/{id} → Events

What happened to a house, cabin, car or boat over time. The section is the contract events log on the same EventRail, as the last zone of the property record. It differs in two places: the type list depends on the property's type, and the server records only acquired, disposed and archive changes. The buttons on each card simulate those property edits, so you can watch the system rows land.

  • ruleThe picker is the matrix. A vehicle offers Serviced, Tyre change, Periodic inspection and Registration first; real estate offers Renovation, Tax assessed and the two tenancy types. The 13 universal members follow, Other last. The 422 is not reachable through the dialog.
  • smart_toySystem-only types are never offered on create. Editing a recorded Archived row shows its type alone under “Recorded automatically”, so the edit can keep it (AC 5).
  • visibility_offEstimates write nothing. The log is read under properties.read; an “estimate added” row would leak what properties.estimates.read withholds. The dialog says a Valued event is a log line, not an estimate.
  • toggle_offNo event changes the property. A hand-written “Disposed of” does not set the disposed date; the Type field's help says so and points to Edit property.
