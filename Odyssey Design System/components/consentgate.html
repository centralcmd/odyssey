2 · Pending — the whole panel skeletons

A part-rendered disclosure is the one outcome to avoid: it would show real prose around values that are about to change. The panel skeletons whole and shape-matched, so nothing shifts when the values land — and there is no moment where a user can read a sentence that is not yet the sentence. Refetched on every open, not once per session: a WASM session lasts days, and a disclosure another admin changed must not stay invisible for that long.

3 · Degraded — the endpoint 503s and compiled fallbacks render

The four values still have compiled fallbacks, so the panel is never empty — but a legal disclosure must not be presented as authoritative when the server could not confirm it. The values render marked as unconfirmed and the affirmation stays disabled: a tick against wording that then changes underneath is consent given to text the user never saw. The way forward is retry, not proceed.
