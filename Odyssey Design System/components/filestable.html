FilesTable <FilesTable files typeFor kinds actions onSave onDelete />

A preset of RecordTable — file rows follow the standard record lifecycle: click a row (or View details) for the read-only detail, Edit swaps in the inline panel for a file's only mutable fields (name + document type — kinds feeds the picker), Save flashes the Saved chip. typeFor(file) resolves each kind's {'{ icon, color, soft }'} (the ACCOUNT_FILE_TYPES registry shape) so a Statement reads the same here as in the upload picker. actions(file) supplies only the file-specific items — Preview (the document viewer), Download, Analyze, Copy ID — slotted between Edit and Delete; host their modals outside the table. “Preview” opens the document; “View details” expands the record. An optional per-row statusBadge ({'{ text, tone?, ariaLabel? }'}) renders an OdsChip next to the file name — here a Review pending · 12 hint for a file with an open, resumable analysis review (meaning carried as text; the row also gains a Resume review menu item).
