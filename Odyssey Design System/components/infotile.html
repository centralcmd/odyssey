InfoTile <InfoTile icon label value foot valueVariant wide />

The richer sibling of MetaTile and StatTile. Each fact reads as its own elevated tile — an icon chip + overline label, a headline value (valueVariant: mono · text · sm), and an optional muted foot. The icon chip defaults to the brand accent; pass iconColor for a per-tile category tint (the Type tile below), or set --odc-infotile-accent on the grid to re-tint a whole set at once (the indigo row). wide spans all columns and lets the value wrap — for a notes tile.
