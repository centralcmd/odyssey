AccountSmartTagsSection <AccountSmartTagsSection tags tagOptions transactions onAddTag onRemoveTag renderTable />

The expanded-account "Smart tags" disclosure: a saved, per-account tag watchlist. Watched tags show as removable .odc-chip.tag chips; the dashed Add tag control opens a checklist where check → add / uncheck → remove (one call each, matching the per-tag endpoints). The header pill counts matching transactions; the body steps through NoSmartTags → Loading → NoTransactions → HasTransactions. The ledger is injected via renderTable (the shared TxnTable), so the section never depends on the table's render contract. Read-only viewers (canWrite=false) keep the chips + table but lose every add/remove control.
