Account custodian <CustodianChip custodian /> · <CustodianSelect value onChange contacts />

Custodian is the optional link from an account to the contact that holds it — the bank for a bank account, the broker for a brokerage, the provider for a pension. It reuses the existing Contact entity rather than a separate institution concept. CustodianChip renders the link on the account card (collapsed row + detail), composing the chip language with the ContactType registry; it is informational only (no per-contact route in v1). CustodianSelect is the optional picker on the create dialog and the inline edit grid — a reuse/extension of Combobox, listing active contacts only, clearable, with no inline create and no type restriction.
