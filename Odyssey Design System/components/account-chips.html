Account detail chips <AccountTypeChip type /> · <AccountStatusChip label tone detail />

These two complete the account-detail chip family alongside CustodianChip — one coherent pill (leading accent · name · muted third segment), used in both the collapsed account row and the expanded metadata grid. AccountTypeChip draws from the ACCOUNT_TYPES registry; AccountStatusChip uses a tone-colored dot for the status state and carries the account's date context (a single date in the row, the full Opened → Closed / Archived lifecycle in the detail tile, where it replaces the former separate Opened / Closed fields).
