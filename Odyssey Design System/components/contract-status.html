Contracts <ContractStatusChip />

ContractStatusChip is the read display of ContractStatus, the status the server derives per request from the contract's dates and its two stamps. Paused replaces Active and nothing else: a terminal fact outranks a temporary one, so a paused contract whose term has run out reads Expired while keeping its pause stamp. Meaning is always carried by the text label — the dot and glyph are aria-hidden. The resolver contractStatusMeta() returns a neutral row for an unrecognised member so a client running behind the API reports a degraded state rather than a wrong one.
