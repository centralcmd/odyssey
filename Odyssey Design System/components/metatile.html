MetaTile <MetaTile label value mono />

Always two per row. Tiles fill the .meta-grid in source order — there is no spanning variant. Long values (descriptions, GUIDs, file names) wrap to multiple lines inside their tile; row neighbors stretch to match, so the grid stays aligned. value is any node — plain text, mono for IDs / codes / timestamps, or a Chip for statuses and types. Absent values render an em dash, never an empty tile.
