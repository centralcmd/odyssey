Smart-tag scope <SmartTagScopeField value term errors onChange /> · <SmartTagScopeSyncPrompt before after scope checked />

The scope is a contract's own date range for the smart-tag match, independent of the term: copied from the term on create, then edited only here. An empty side is open. The field never validates against the term — a scope before the start or after the end is the point of the feature — and states the relation in a sentence so the strip is never the only signal. Client checks mirror the server: a date outside 1 Jan 1900 – 31 Dec 9999 is a 400; a start after the end is a 422 keyed to Match until; the same day on both sides is valid. Days are sent as UTC midnight (2027-06-30T00:00:00Z), never with an offset.
