Homeowner association is a real-estate property's optional link to the Organization contact that administers it. The picker offers active Organizations only, so the server's 400 (not found / archived) and 422 (not an organization) are rare; when they arrive they sit on the field. A link that was valid when set and has since been archived or re-typed is kept: the server only re-checks a changed id, so the dialog states the contact's state and how to change it, and Save is not blocked. Deleting the contact clears the link; the property record then shows no tile.
