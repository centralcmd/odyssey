Journal module <TodoStatusChip /> · <JournalPhotoGallery /> · <TaskBoard />

TodoStatusChip renders a task's single kanban status (Backlog · Doing · Done · Archived); the state meaning is always the visible label, never colour or glyph alone. JournalPhotoGallery is the responsive, keyboard-focusable thumbnail grid on a journal entry — <img loading="lazy"> at native fidelity in production, a striped placeholder with a monospace photo label + filename in mocks. TaskBoard is the three-column kanban with dual-path moves: HTML5 drag-and-drop for pointer users and an always-present move-button cluster (up / down / previous column / next column) for keyboard users, with every move announced through a polite live region. Columns are labelled landmark regions with text counts.
