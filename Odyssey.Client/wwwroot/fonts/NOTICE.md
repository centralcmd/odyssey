# Bundled webfonts — attribution

The `.woff2` files in this directory are third-party fonts redistributed unmodified as
part of Odyssey. They are self-hosted rather than loaded from the Google Fonts CDN so the
application makes no third-party requests at runtime and no visitor IP address is
disclosed to Google.
